# SahaSetu Admin Dashboard

## Run
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open `index.html` with Live Server (recommended) or double-click it.
4. The Admin Login appears.
5. Enter the displayed/default phone number and click **Send OTP**.
6. Enter the **Demo OTP shown on the screen** and click **Verify & Login**.

## Logout
Use the **Logout** button in the admin sidebar. You will return to OTP login.

## Important
This is a front-end prototype. The OTP is generated locally for demonstration. A real SahaSetu deployment needs a backend authentication service/SMS OTP provider.
